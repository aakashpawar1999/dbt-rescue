# DBT Rescue three-minute demo script

Use a clean, signed-out browser. Enter only the fictional reference
`DBT-SUNITA-001`. The script demonstrates the public build; it must not show a
real account, credential, editor, or live government response.

| Time | Action | Spoken cue |
| --- | --- | --- |
| 0:00–0:25 | Show the landing page and prototype notice. | Sunita is expecting a farmer-benefit payment. A status can say money reached a mapped bank while the account she checks is different. The hard part is knowing which organisation can resolve the mismatch. |
| 0:25–0:45 | Open the simulation disclosure. | PFMS, NPCI, banks, and scheme systems already provide separate pieces. DBT Rescue connects the evidence, owner, next action, and follow-up around one recovery outcome. |
| 0:45–1:05 | Leave Sunita selected and submit the fictional reference. | This is a safe local fixture, not a live lookup. No Aadhaar, bank number, OTP, or login is needed. |
| 1:05–1:30 | Show the payment timeline. | The timeline keeps each source and timestamp visible. It shows the newer mapped Bank B credit and the older Bank A check as a conflict instead of inventing a missing payment. |
| 1:30–1:55 | Open the diagnosis and audit details. | The reviewed rule says to check Bank B first. The audit view exposes the fictional event, reason, source, route, review date, and rule status. |
| 1:55–2:20 | Prepare and print the trace request. | DBT Rescue gives the responsible trace desk and a masked, printable request. It does not file a complaint or move money. |
| 2:20–2:40 | Record the fictional acknowledgement. | This acknowledgement is simulated. A real service would receive its confirmation from the responsible organisation. |
| 2:40–2:55 | Advance to the trace-confirmed receipt. | The local tracker records a simulated resolution state while keeping the boundary clear: this is not a bank confirmation. |
| 2:55–3:00 | Return to the disclosure and show the submission links. | The build is functional for three synthetic cases; integrations, eligibility, correction, and payment movement remain outside the prototype. Codex contributed to research translation, implementation, testing, accessibility, debugging, and documentation. |

If the public page fails, use the matching local `dist` artifact. If the local
artifact fails, play the captioned recording or read the transcript; do not
claim that an unverified path works.
