# DBT Rescue 1.0.0

DBT Rescue now opens with a professional product landing page. The separate
[/demo](https://dbt-rescue.aakashpawar1999.chatgpt.site/demo) workspace brings
the payment explanation, responsible owner, next action and evidence together.

- Four starts: try a safe example, enter a fictional reference, understand a
  supported status, or find official guidance when status is inaccessible.
- Replaced language buttons with a native English/Hindi dropdown.
- Three English/Hindi fictional journeys with expandable source provenance,
  assisted display mode, and printable trace/correction guidance.
- Safer diagnosis and recovery: missing or conflicting credit evidence cannot
  imply success; reissue requires a separate simulated credit confirmation.
- Device-local resume preserves the selected case, view, language, display mode
  and recovery proof for a fixed 24 hours. Start over clears the saved case.
- Corrected rule/event localization, document language, invalid transitions,
  direct demo refresh, and history/reset behavior.

## Scope and limitations

This is an independent synthetic demo, not a government service. All people,
references, payments, acknowledgements and outcomes are fictional or simulated.
No real Aadhaar, bank, OTP or government-login information should be entered.
No real payment system, model API or identity service is contacted.

LocalStorage is device-local and unencrypted. Assisted mode changes presentation;
it is not a consented delegated account. Follow-up copy claims no official SLA.
The landing page is English; the working demo supports English and Hindi.

The user approved shipping this current candidate. The wider twelve-case,
task/deadline, consented-helper, authenticated-backend, model, evidence-storage,
and operations scope is deferred to planned 1.1.0. Formal accessibility,
linguistic, security and operational certification are not claimed.

Rollback target: the previous verified Sites version 10 and the retained
v0.6.4 GitHub tag. The v1.0.0 completion record identifies the new deployment.
