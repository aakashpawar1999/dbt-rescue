# dbt-rescue 0.6.4

## Delivered

0.6.4 keeps the existing language control beside the DBT Rescue brand on narrow
phones. At 320px and 360px, the bordered box stacks English above Hindi and
the title uses a compact readable size. The existing controls, translations,
focus treatment, touch targets, and recovery behavior remain unchanged.

The patch uses the existing React markup and native CSS only. It adds no
dependency, fixture, runtime data, integration, or backend behavior.

## Verification

- The focused responsive regression suite covers the narrow vertical control,
  compact title, and existing breakpoint placement behavior.
- Browser geometry checks cover 320, 360, 439, 440, 600, 768, and 1280 CSS
  pixels with no horizontal overflow, header overlap, clipped title, or
  inaccessible language control.
- Bun lint, build, tests, release-safety, targeted credential scan, and Git
  diff checks are required before release promotion.

## Boundary

All cases, payment events, acknowledgements, corrections, reprocessing, and
credit states remain synthetic or simulated. DBT Rescue does not connect to
live government or banking APIs, process real citizen data, determine
eligibility, correct real records, release money, or confirm a real credit.
