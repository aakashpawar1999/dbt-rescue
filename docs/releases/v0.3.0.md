# dbt-rescue 0.3.0

## Outcome

A citizen or helper can complete any supported fictional payment-recovery
journey in English or Hindi on a small mobile screen, with assisted context,
accessible controls, low-data presentation, and printable instructions.

## Included

- English/Hindi copy across lookup, diagnosis, owner/action guidance, packet, acknowledgement, tracker, and safety disclosure.
- State-preserving language and assisted-mode switches.
- Deterministic diagnosis for all three synthetic cases.
- 360px mobile layout, visible focus, semantic labels/landmarks, live announcements, and absolute timestamps.
- Bilingual browser-printable trace/correction packets with masked identifiers and source context.

## Verification

- 22 automated tests passed.
- `bun run lint` passed.
- `bun run build` passed.
- `bun install --frozen-lockfile` resolved without changes.
- Browser checks covered English/Hindi, all three cases, assisted mode, browser Back, 360px overflow, validation focus, packet output, and recovery announcements.
- Human review approval was received in the task thread for Hindi terminology and the documented keyboard, screen-reader, zoom, contrast, and print checks.

## Limitations

This is an independent static hackathon prototype. It has no backend,
authentication, live government/bank integration, real beneficiary data, or
real payment movement. The release target is `release-ready`; no public
deployment is claimed here.
