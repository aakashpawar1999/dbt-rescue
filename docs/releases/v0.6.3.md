# dbt-rescue 0.6.3

## Delivered

0.6.3 corrects the responsive header placement of the existing language
toggle. From 440px through mobile and tablet widths, the toggle sits at the
top-right beside the DBT Rescue logo and title while assisted mode and `Start
over` remain on the following row. Below 440px, the language control moves to
its own right-aligned row so neither the brand nor the controls overlap or
widen the page. At 768px and above, the existing single-row desktop header and
rightmost language placement remain intact.

The patch uses the existing React components and native CSS Grid. It adds no
dependency and changes no fictional fixtures, diagnosis rules, recovery
behavior, translations, data handling, or safety boundary.

## Boundary

All cases, payment events, acknowledgements, corrections, reprocessing, and
credit states remain synthetic or simulated. DBT Rescue does not connect to
live government or banking APIs, process real citizen data, determine
eligibility, correct real records, release money, or confirm a real credit.
