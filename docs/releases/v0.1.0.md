# dbt-rescue 0.1.0

This release is a release-ready independent hackathon prototype.

## Demonstrated outcome

A citizen enters `DBT-MEENA-003`, sees the fictional payment timeline, learns
that no active DBT bank mapping is available, receives the bank correction
action and document list, prints a masked correction request, records a
fictional acknowledgement, and follows simulated reprocessing through account
credit.

## Verification

- `npm install` — dependencies resolved with no reported vulnerabilities.
- `npm run lint` — TypeScript check passed.
- `npm test` — 6 tests passed, 0 failed.
- `npm run build` — Vite production build passed.
- Browser journey — lookup, timeline, diagnosis, packet, acknowledgement, and final tracker verified locally.
- Mobile check — 360 px viewport had no horizontal overflow.
