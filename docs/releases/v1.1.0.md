# DBT Rescue 1.1.0

This release focuses the public demo controls around a calmer header and a
recording-friendly Mobile frame view.

- Removed the direct frame item from the landing-page main navigation.
- Renamed the demo options to `Reset Demo`, `Assisted Mode` / `Citizen Mode`,
  and `Mobile frame`.
- Replaced the language dropdown glyph with an aligned CSS chevron while
  preserving the native disclosure, seven language choices, Escape dismissal,
  and focus return.
- Removed Frame colour and Background from the frame view.
- Rebuilt the frame toolbar around Back to demo, zoom, Fit, Reload demo and
  Recording view with responsive wrapping and 44px controls.

## Verification

The release is gated by Bun frozen-install, lint, focused and full tests,
production build, diff and credential/runtime scans, plus browser checks for
the standalone and embedded demo, menu interactions, frame controls, recording
view, keyboard exit, and 320–1280px responsive geometry.

## Scope and limitations

DBT Rescue remains an independent synthetic browser demo. It does not contact
government, bank, identity, payment, analytics or model services, and the
Mobile frame view does not record video itself. No formal accessibility,
native-speaker, security or operational certification is claimed.

Rollback target: the verified v1.0.0 source and existing Sites version 11.
